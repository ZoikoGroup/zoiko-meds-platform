# zoiko-meds-platform

Monorepo for the Zoiko Meds platform, containing both the frontend and backend applications.

## Project Structure

```
zoiko-meds-platform/
├── frontend/   # Client-side application (UI)
├── backend/    # Server-side application (API, business logic)
└── README.md
```

## Frontend

The `frontend/` directory holds the client-side application.

```bash
cd frontend
# install dependencies and run the dev server once set up
```

## Backend

The `backend/` directory holds the server-side application (API and business logic).

```bash
cd backend
# install dependencies and run the server once set up
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ZoikoGroup/zoiko-meds-platform.git
   cd zoiko-meds-platform
   ```
2. Set up the frontend and backend by following the instructions in their respective directories.
